# ToneShift
ToneShift è un programma in Python che serve a corregge eventuali errori grammaticali in una frase (es mancanza di punteggiatura o parole errate). ToneShift oltre a correggere la grammatica può anche modificare il registro linguistico, ci sono 6 tipi di registri linguistici: formale, informale, amichevole, persuasivo, assertivo o semplificato.
