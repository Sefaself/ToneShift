# ToneShift

ToneShift è un programma in Python che corregge automaticamente errori grammaticali (punteggiatura, parole errate, costruzioni scorrette) e modifica il registro linguistico di una frase.

## ✨ Funzionalità

- Correzione grammaticale automatica  
- Sistemazione della punteggiatura  
- Modifica del tono del testo  

---

## 🗣️ Registri disponibili

- Formale  
- Informale  
- Amichevole  
- Persuasivo  
- Assertivo  
- Semplificato
